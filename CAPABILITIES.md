# Qualification boundary

Linux local MCP install, doctor, Fleet status/memory/control, Engine file write/read, Knowledge read and local bare-origin commit/push/readback, and uninstall are tested without provider calls. No worker/model is spawned. MCP headings and icons are metadata/result text; native agent tool row rendering is not delivered. Browser actions, Windows, final integrated V4 pin, real relay/account enrollment, real remote machines, relay lease renewal, multi-device concurrency and two-transport active revocation remain outside this candidate qualification.
